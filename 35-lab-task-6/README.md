# Lab Task 6

This folder groups the two files labeled as Task 6 questions.

- `question-1-weekday.asm` maps numbers 1–7 to weekday names and reports other values as invalid.
- `question-2-grade.asm` uses mark thresholds to display a letter grade and rejects values outside its apparent 1–100 range.

**Concepts:** comparisons, labels, conditional jumps, input validation, and console output.

**Review note:** The source's printed weekday strings include apparent spelling mistakes. They are left as written so the original code stays intact.
